# 📊 AI Data Quality Agent

An AI-powered web application that analyzes the quality of CSV datasets and generates intelligent business insights using Google's Gemini AI.

---

## 🚀 Features

- 📂 Upload any CSV dataset
- 👀 Preview uploaded data
- 📋 Display dataset summary
- ⚠️ Detect missing values
- 🔄 Detect duplicate records
- 📈 Detect outliers using the IQR method
- 🏆 Calculate an overall Data Quality Score
- 🤖 Generate AI-powered Business Insights
- 🧹 Provide Data Cleaning Recommendations
- 📊 Suggest Dashboard KPIs for business reporting

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Google Gemini AI
- Google Generative AI SDK
